Smart Hydroponics Monitoring

Sistem monitoring hidroponik berbasis IoT untuk memantau suhu, kelembapan, pH air, TDS, water level, serta mengontrol pompa nutrisi secara real-time.

Fitur Utama

Smart Hydroponic Monitoring menyediakan berbagai fitur monitoring dan kontrol tanaman hidroponik secara real-time.

Monitoring Sensor

🌊 Suhu Air

Monitoring suhu air menggunakan sensor DS18B20 secara real-time.

🌡️ Suhu Udara

Monitoring suhu lingkungan menggunakan sensor DHT22.

💧 Kelembapan

Menampilkan kelembapan udara secara real-time.

🧪 pH Air

Mengukur tingkat keasaman air untuk menjaga kondisi tanaman.

⚡ TDS

Monitoring kadar nutrisi menggunakan sensor TDS.

🚰 Water Level

Monitoring tinggi air pada reservoir hidroponik.

Kontrol Otomatis

🟢 Pompa Nutrisi A

Mengontrol pemberian Nutrisi A secara otomatis.

🟢 Pompa Nutrisi B

Mengontrol pemberian Nutrisi B secara otomatis.

🧪 Pompa pH Up

Menambahkan larutan pH Up saat pH terlalu rendah.

🧪 Pompa pH Down

Menambahkan larutan pH Down saat pH terlalu tinggi.

Keunggulan Sistem

📈 Monitoring Real-Time

Seluruh data sensor diperbarui secara langsung.

📱 Responsive

Dapat diakses melalui Laptop maupun Smartphone.

☁️ IoT

Terintegrasi dengan ESP32 melalui jaringan internet.

🔒 Aman

Akses dashboard hanya untuk pengguna yang login.

Tentang Sistem

Smart Hydroponic Monitoring System merupakan aplikasi berbasis web yang digunakan untuk memonitor kondisi tanaman hidroponik secara real-time menggunakan sensor IoT seperti DHT22, DS18B20, Sensor pH, TDS, Water Level Float serta kontrol pompa otomatis.
